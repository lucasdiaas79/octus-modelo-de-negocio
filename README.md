# Studio Octus · Conceito, modelo de negócio e operação

Apresentação web interativa (13 telas) sobre o que é o Studio Octus, como opera e como o modelo evolui. Apenas identidade Octus.

## Executar

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # site estático em /dist
npm run build:single # um único index.html em /dist-single
```
